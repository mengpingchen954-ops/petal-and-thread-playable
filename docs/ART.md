# 美术、资源与技术约束

## 视觉方向

原创「花间裁衣 / Petal & Thread」。微缩裁缝工作室，暖木、奶油白、鼠尾草绿和低饱和花色；圆角珐琅缝纫机、黄铜工具、木线轴、陶瓷花瓶。服装保留经纬织纹和缎面光泽，区别于黏土和橡胶质感。

游戏本体使用 Three.js 的 3D 几何体和物理材质；HTML/CSS 只负责界面。没有用静态插画冒充制作场景或最终模特。

## 资源清单和来源

| 资源 | 制作方法 | 来源 |
|---|---|---|
| 木桌、线轴、缝纫机、剪刀、尺子、针包、花瓶、陶杯 | 圆角体、旋转体、挤出形状、曲线管道 | 本次原创程序化建模 |
| 裙装纸样、前后片 | 固定版型路径 + 带厚度挤出几何 | 本次原创 |
| 立体裙装 | 参数曲面、双面布材质、肩带、腰线、裙摆包边 | 本次原创 |
| 裙摆运动 | 极轻微的受控 morph 变形，非真实物理 | 本次原创 |
| 裁缝模特、台座、帘幕和盆栽 | 旋转体、曲面、基础几何组合 | 本次原创 |
| 花饰、蝴蝶结、纽扣 | 小型 3D 几何体、缎带尾与缝线 | 本次原创 |
| 木纹、经纬织纹、格纹、波点、裁切垫刻度 | Canvas 纹理；固定随机种子控制木纹 | 本次原创 |
| 品牌图形、工具和 UI 图标 | 手写 SVG 路径 | 本次原创 |
| 操作声、裁缝提示声、完成声 | Web Audio 合成 | 本次原创，无第三方采样 |
| 字体 | 用户系统的宋体、微软雅黑等回退字体 | 不分发外部字体 |

当前游戏不含敌人、武器或战斗，因此没有创建不相关的战斗资源。

## imagegen 的实际情况

已读取本会话安装的 imagegen 技能。当前工具清单没有可调用的内置 image_gen 图像生成能力，因此**没有实际生成 AI 位图，也不声称使用过 imagegen 成品**。该技能的 CLI/API 备用路径需要显式选择及 OPENAI_API_KEY，本任务没有切换到付费 API 路径。依据用户明确允许的备用方案，全部游戏美术采用程序化 3D、Canvas、SVG、CSS 和物理材质完成。

图像生成未使用，因而没有已执行的图像生成提示词或生成文件路径。若后续启用，可优先生成木纹/织物微表面或概念稿；仍保留当前可运行的完整美术。

## 渲染与流畅性

- ACES 色调映射、环境光、冷暖补光及 2048 级阴影。
- 织纹 bump 与物理材质 sheen 区分柔棉、亚麻和缎面。
- 布料和裙装由同一作品数据生成；装饰从平面版型坐标映射到服装表面法线。
- 大量针脚使用 InstancedMesh，避免每一针都是独立绘制调用。
- 动态几何、材质和 Canvas 贴图在重建时释放，避免持续制作时无界累积。
- 像素比限制到 1.6；无重后处理、无运行时网络资源。
- 工作台阴影在内容发生变化时更新；试衣间细微运动的阴影低频更新，减少重复绘制。
- 减少动态效果偏好会停用裙摆的轻微运动。

## 使用许可

上述模型、纹理、图标和合成声音为本项目现场原创生成，未使用原作截图、模型、音乐或标志作为游戏资产。商店截图与网页截图只保留在 `artifacts/` 作为研究记录，不进入 `dist/`。

Three.js 为 MIT，许可证见 `docs/THREE-LICENSE.txt`；Vite 为 MIT；Playwright 为 Apache-2.0，仅用于开发测试。正式运行包不依赖 Playwright 或 Vite。
