# 实际验证记录

日期：2026-10-16（Asia/Shanghai）。测试使用真实 Chrome + Playwright 驱动鼠标，读取只读诊断接口投影实际 3D 路线坐标。测试通过鼠标输入推进工序，**没有用接口直接把裁剪/缝合进度设满**。

## 环境

- Windows，Chrome 155 / WebGL 2，GPU 硬件加速。
- CPU：Intel Core Ultra 7 265KF。
- GPU：NVIDIA GeForce RTX 3060，ANGLE Direct3D 11。
- RAM：32 GB。
- 完整操作：1440×960，DPR 1。
- 额外布局检查：1366×768、390×844。后者是桌面浏览器模拟视口，不代表真实手机验证。

## 分阶段实测与修正

1. 运行基础工作台、布料和相机，截图发现初始曝光偏高；降低环境光与曝光，增强木纹与纸样路线对比。
2. 通过真实轨迹完成两片裁剪和三段缝合，验证内部空白点击不增加进度、取消工具、局部进度和笔画撤销重做。
3. 加入装饰、试穿、交付与作品集，做出蓝色亚麻格纹「花园来信」及粉色缎面波点「莓粉舞曲」。检查发现上身包覆不足，修正裙身半径、肩带、装饰法线与位置；帘幕改为完整环形，去掉明显背景边缘。
4. 重新构建并在正式服务器 `127.0.0.1:4173` 走完整流程；增加资源释放、针脚实例化和阴影更新优化；再次通过完整测试。额外验证 WebGL 断开恢复、无外网资源请求和静态服务器路径边界。

## 性能与构建

最后一次完整流程采样：工作台约 **54 FPS**，试穿约 **56 FPS**，最终稳定画面 **60 FPS**。单独复核性能时，工作台连续三次与试穿均为 **60 FPS**；另一次同时打开预览与截图的启动采样为 **47 FPS**。这是本机 Chrome 的短时采样，不是所有设备上的帧率保证。

阴影优化后稳定帧：工作台约 185–187 次绘制、约 7.8–8.3 万三角形；试穿约 38–50 次绘制、约 3.1–3.6 万三角形。阴影更新帧开销较高；裁剪和装饰操作时会按需要重新生成动态内容。

正式构建通过。主要 JS 约 655 kB，gzip 约 172 kB；CSS 约 21 kB。Vite 有 Three.js 所在单文件超过 500 kB 的体积提示，无构建错误；没有为消除提示而引入加载复杂度。全部运行资源均在 `dist/` 内。

## 已知边界与未验证项

- 只有固定一款版型，裁剪不会生成任意拓扑，缝合是受控的制作表现，裙摆运动不是完整布料物理。
- 展示材质有真实光照、织纹与光泽差异，但仍是程序化微缩风格，未达到扫描布料或照片级细节。
- 作品集依赖当前浏览器和端口的本地存储；需导出 JSON 才能跨浏览器长期保管。
- 未在真实手机、Safari、Firefox、集成显卡或低端设备上实测；手机只检查布局，主操作按鼠标设计。
- 合成音效触发已在浏览器执行，没有做主观听感与真实音箱测试。
- 没有外部发布，也没有验证原作可执行版本的输入机制或完整教程；参考边界见 REFERENCE.md。
