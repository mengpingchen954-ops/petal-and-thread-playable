### 工作台与镜头

已看到：裁缝店室内作为背景，顾客交谈视角面向工作台和店内；排料时有俯视的布料工作区；缝制演示为接近缝纫机针脚与送布区域的镜头；试衣展示可见模特、旋转与缩放方向按钮，以及背景/灯光相关选项。

本版设计：真实 3D 的微缩木工作台与单独的环形帘幕试衣场景；工具步骤采用更靠近桌面的镜头；右键 OrbitControls 环绕、滚轮缩放、恢复视角。原创奶油色/鼠尾草绿界面，不复刻原作店面和人物。

### 制作工序与操作

官方文字：选择布料、排料制版、缝制衣物、添加装饰；每块裁片可以使用不同面料；列出棉、亚麻、羊毛、丝绸、天鹅绒等类型。

已看到：素描本式设计页、裙身/袖子/裙摆等部件选项、纸样和布料选择区；纸样的旋转框、旋转箭头与裁剪工具图标；机器针脚附近的送布/缝合演示；装饰界面列出纽扣、蝴蝶结、花饰、绳带类选项，边线上出现节点。**没有亲自操作原作，因此不能确定其裁剪输入容差、缝合按键、节点语义、自由切割范围或失败规则。**

本版设计：固定一件吊带 A 字裙，两片整身纸样。鼠标轨迹只更新附近路线采样点，左右边和腰线为三条预定义连接边。装饰采用真实 3D 花饰、蝴蝶结和纽扣，可移动、旋转、删除及撤销；不假设这是原作的精确操作方法。

### 材料变化与反馈

已看到：不同的布料颜色、格纹和花纹；纸样覆盖布料；缝纫机中的布料片；模特上的已完成服装；装饰演示中的连接线与节点。官方文字把实际排料、裁剪和最终表现关联起来。

本版设计：面料实时改变；裁剪未完成处为虚线、经过处留下切口；每片完成后抬离原布料，两片均完成后撤去余料；缝线以立体针脚逐点增长、背片逐步靠拢；完成后在模特上用参数曲面呈现。采用固定褶皱与轻微摆动，**没有完整布料模拟或任意切割拓扑**。

### 成品展示

已看到：官方截图有精细紫色礼服、花边和花朵装饰；模特展示界面有相机、旋转、缩放、灯光、Export/Import 按钮；店内顾客回应画面有星形评价。官方文字提到交付、声望、金币、橱窗出售。

本版设计：只有一份委托，逐项判断颜色、花饰与制作完成度；成功回应会提及蓝色和花饰数量；作品照片为 PNG，作品数据为 JSON，本地存档。**未验证原作 Export/Import 的格式，不把本版 JSON 系统称为原作功能。**本版没有金币、声望、橱窗和经营。

已看到：草图本、材料列表、要求面板、风格属性条、预算数字、可见的工序完成文字和顾客对话。没有访问原作完整可操作的新手流程，因此**原作教程顺序、失败处理、撤销和保存行为未核实**。

## 仍存在的差异

本版的款式、裁片和连接方式大幅简化；没有混合裁片用料、原作的多部件/复杂版型、细致送布工序、城镇人物和经营；美术是原创程序化 3D 与物理材质，尚未达到扫描材质或影视级布料的真实度。输入方式、镜头和 UI 为本版自行设计，之后可以在获得更多可操作参考后调整。
